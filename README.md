# Buy Better Finds

Astro website for Buy Better Finds.

## Run in Visual Studio Code

```bash
npm install
npm run dev
```

Open the local URL shown by Astro.

## Build

```bash
npm run build
```

## Deploy

Commit and push the project to GitHub. Cloudflare Pages can then deploy the `main` branch.
